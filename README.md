# Usage
 Download the "source code" above (although it is not actually source code). Install the APK inside, and extract the rest to /sdcard/Arc4/. Note that you must extract them into the directory itself (e.g., /sdcard/Arc4/char/).

 Extract your prepared custom charts to /sdcard/Arc4/songs/.

 Open Settings and grant Arcaea all-files access permission. Different systems may require extra steps; please search for them yourself.

 Now you can open Arcaea and play normally. You can also change other content in it, such as character artwork.

# Notes
 Only armv8l is supported; other architectures are not supported.

 If you install it to adoptable storage or external storage, the extraction location remains unchanged because this path is hard-coded, unless you use a symbolic link.

 Some systems cannot use it, such as MIUI.

 Songs placed in songs should follow the example format (e.g., 1080_base.jpg should be named base.jpg).

 Packs added to packlist must not include the img parameter.

# Known Issues
 Sky notes with y > 2.1 cannot be hit.

 6K chart edge rendering may have issues.

 Lane divider transparency is displayed incorrectly.

 Tempestissimo must not be present in songlist; if it is, the game will crash.

 If the BEYOND difficulty has unlock conditions, regardless of the specific unlock conditions, that difficulty cannot be selected in-game.

 It is best to keep Sayonara Hatsukoi in songlist to prevent some songs from crashing when opened.
